Hermes privacy policy

Last updated October 19, 2026

Hermes is a personal Telegram assistant built and run by Elmir Abdullaiev. It answers only one allow-listed Telegram user, its owner. It is not offered to anyone else, and no one else can sign in to it.

What it accesses

When the owner signs in with Google, Hermes asks for two permissions:

  • Gmail, read-only (gmail.readonly): to read selected emails, such as campus event and job-alert emails, and send the owner a short daily summary. It cannot send, delete or change email.
  • Google Calendar (calendar): to read the owner's calendar and add or change events when the owner asks it to.

How the data is used

  • Data is used only to answer the owner's own requests and to send the owner summaries in Telegram.
  • The text of the emails being summarised is sent to Google's Gemini API to write the summary.
  • Google sign-in tokens and the assistant's conversation memory are stored on the owner's private server. They are not shared, sold or used for advertising.
  • Use of information received from Google APIs follows the Google API Services User Data Policy, including its Limited Use requirements.

Removing access

Access can be revoked at any time at myaccount.google.com/permissions. Revoking it stops Hermes from reading Gmail or Calendar immediately.
